# Dependencies of the scrapeMM *server*, on top of the client package's own.
#
# Deliberately not a pyproject extra: the server is not installable from PyPI in any
# meaningful sense, because pip cannot give it Playwright's browsers, FFmpeg or the
# Xvfb display that the Archive.today CAPTCHA panel drives. It ships as a Docker image
# built from this repo, and this file is what that build installs.
#
# Working on the server from a checkout:
#   pip install -e .
#   pip install -r requirements-server.txt
#   playwright install
